# JoyEvents

趣味玩法合集模组：把各种整活玩法打包在一起，**每个玩法都能单独开关、单独调参**，并且配置界面里带完整说明

- 游戏版本：Minecraft **1.21.1**
- 加载器：**NeoForge 21.1.250+**
- 依赖：无（仅需 NeoForge）
- 许可证：MIT ｜ 作者：Mengy ｜ 版本：1.0

## 玩法一览

> **所有玩法默认关闭**，需要自己在配置界面或命令里打开

| 玩法         | 说明                                          | 默认周期 | 主要参数 |
|------------|---------------------------------------------|---|--|
| **位置互换**   | 把每名玩家送到"离自己最近的那名玩家当前所在的位置"，全体同时生效           | 3 分钟 | 周期、触发公告 |
| **共享生命**   | A 模式：只共享伤害，一人挨打其他玩家按比例一起受伤；B 模式：所有人共用同一条血条与同一条饥饿条，一人死亡全员死亡 | 常驻效果 | 模式、伤害传递比例、共享条上限、是否允许回血、死亡后重置比例 |
| **随机传送**   | 把每名玩家随机传送到当前位置附近的安全落点                       | 3 分钟 | 周期、半径、维度策略、是否只找安全落点 |
| **开发中...** | 敬请期待                                        |  |  |

玩法细节：

- **位置互换**：先给所有人拍一张位置快照，再统一传送，所以是"位置映射"而不是两两配对——三个人同维度时可能出现 A→原B点、C→原B点（两人落在同一坐标）跨维度不比距离，同维度没有别人时该玩家不传送传送后清除坠落伤害
- **共享生命**
  - **共享生命 A 模式**：只共享伤害、不共享回血。其他玩家受到的伤害 = `挨打者护甲结算后的实际伤害 × 配置百分比`（默认 100%，即挨 6 点其他人也各掉 6 点；设 50% 则各掉 3 点）对方自己的护甲会再减免一次，所以护甲在这个模式下依然有用
  - **共享生命 B 模式**：所有人共用同一条血条和同一条饥饿条，**共享条是唯一真实数值**——默认上限 20 点（10 颗心），你的血条上显示的数字就是共享条的数值（3 人共用 20 点时，共享条剩 14，三个人看到的都是 7 颗心）伤害在护甲结算后进入共享条，共享条见底则全员倒下并按配置比例重置
  - **共享生命 B 模式的收支规则**：一个人吃东西，全队饥饿条一起涨；回血与体力消耗按"一个身体"的速率计算（否则人越多共享条自愈越快）；回血会真实消耗共享饥饿条（约 1.5 点饥饿换 1 点血，与原版一致）
- **随机传送**：会避开岩浆、火、仙人掌、细雪、虚空和下界基岩顶；找不到安全落点就跳过该玩家（宁可不传送，也不埋人）

## 怎么打开玩法

**方式一：配置界面（推荐）**

进入世界后 → `Mods` → `JoyEvents` → `Config` → **Server Config**，每个玩法第一项就是 `enabled` 开关，下面跟着它的参数；**鼠标悬停在任意选项上会显示中文说明**

> 玩法参数属于**服务端配置**，只有在服务端运行时才能编辑，所以请进世界后再改；主菜单里能打开的只有 Client Config（HUD 显示偏好）
> 如果你把单人世界"开放到局域网"，Server Config 会变成只读（NeoForge 的设定），此时请用下面的命令

**方式二：游戏内命令**（需要 OP / 权限等级 2）

```mcfunction
/joyevents status                      # 查看所有玩法的开关状态、剩余秒数与当前细节
/joyevents enable  <玩法>              # 启用，立即生效并写回配置文件
/joyevents disable <玩法>              # 停用，同时把血量等副作用回滚
/joyevents trigger <玩法>              # 立刻触发一次，不用等周期（调试神器）
```

玩法 ID：`position_swap`、`random_teleport`、`shared_health`

**方式三：改配置文件**

- 玩法参数：`config/joyevents-server.toml`（**单人游戏所有存档共用这一份**）
- HUD 显示：`config/joyevents-client.toml`

改完保存即生效，倒计时会按新周期重新开始，不必重启游戏

> 想让**某个存档**用不同的玩法规则？把 `joyevents-server.toml` 复制到该存档的
> `saves/<世界名>/serverconfig/` 目录下再改，那份会覆盖全局配置（这是 NeoForge 自带的机制）

## HUD 显示

玩法运行时，屏幕左上角会显示倒计时；可单独开关的项（在 Client Config 里）：

- 【位置互换】倒计时 / 目的地（显示你将传送到谁的位置）
- 【随机传送】倒计时
- 【共享生命】共享条余量与百分比

按 F1 隐藏界面或开启 F3 调试界面时，HUD 会自动避让

## 从源码构建

```bash
./gradlew build          # 产物在 build/libs/joyevents-1.0.jar
./gradlew runClient      # 启动开发客户端
./gradlew runServer      # 启动开发服务端（首次需要先同意 run/eula.txt）
```

需要 JDK 21

## 已知限制

- 旁观者永不参与任何玩法；创造模式玩家默认不参与共享生命（可在配置里改）
- 共享生命 B 模式的共享条**不随人数变化**：3 人共用 20 点血条，等于每人只分摊到 10 颗心的全队总量，人越多整体越脆
- 共享生命 B 模式下吸收之心（金苹果的额外血量）不生效，因为共享条才是权威数值；原版"吃饱回血快"依然有效（共享饥饿条越满，回血越快）
- 共享生命 A 模式没有绝对伤害上限：100% 时一人挨 6 点、3 人合计掉 18 点，容易被打崩，可把比例调到 30%~50%
- 位置互换只在同一维度内配对，跨维度玩家互不影响
- 随机传送会把目标区块加载出来（这是传送本身的开销），`max_attempts` 调大能找到更好的落点，但加载的区块也更多
- 世界里没有任何玩家时，倒计时会停住而不空转
