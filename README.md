# JoyEvents

趣味玩法合集：把各种整活玩法打包在一起，**每个玩法都能单独开关、单独调参**，配置界面里带完整说明

- Minecraft **1.21.1** ｜ **NeoForge 21.1.250+** ｜ 无其他依赖
- 版本 **1.1** ｜ 作者 Mengy 

## 玩法一览

> **所有玩法默认关闭**，需要自己在配置界面或命令里打开

| 玩法 | 说明 | 主要参数 |
|---|---|---|
| **位置互换** | 把每名玩家送到"离自己最近的那名玩家当前所在的位置"，全体同时生效（默认 3 分钟） | 周期、触发公告 |
| **共享生命** | A 模式：只共享伤害，一人挨打全员按比例一起受伤；B 模式：所有人共用同一条血条与饥饿条，一起生一起死 | 模式、伤害传递比例、共享条上限、是否允许回血、死亡后重置比例 |
| **随机传送** | 把每名玩家随机传送到当前位置附近的安全落点（默认 3 分钟） | 周期、半径、维度策略、是否只找安全落点 |
| **物品赌博** | 每次触发按概率获得随机物品、丢掉背包一整格、或把一整格换成完全随机的物品 | 9 种触发方式、结果概率、数量区间、物品权重表、黑名单、冷却 |
| **开发中...** | 敬请期待 | |

几个容易误解的点：

- **位置互换**是"位置快照映射"而不是两两配对 —— 三人同维度时可能出现两个人都被送到同一个坐标；跨维度不比较距离，同维度没有别人时不传送
- **共享生命 A 模式**传递的是"挨打者护甲结算之后"的实际伤害 × 配置比例，对方自己的护甲会再减免一次（护甲依然有用）
- **共享生命 B 模式**里共享条就是唯一真实数值：默认上限 20 点，你的血条上显示的数字即共享条数值（3 人共用 20 点、剩 14 时，三个人看到的都是 7 颗心）
- **物品赌博**的获得与丢失是两次独立掷骰，**两者同时命中就是"替换"**，所以替换概率 = 获得概率 × 丢失概率（默认 50% × 50% = 25%）

## 使用

**打开玩法**：进入世界后 → `Mods` → `JoyEvents` → `Config` → **Server Config**，每个玩法第一项就是 `enabled`，下面跟着参数；**把鼠标停在任意选项上会显示中文说明**

**游戏内命令**（需要 OP / 权限等级 2）：

```mcfunction
/joyevents status                  # 查看开关状态、剩余秒数与当前细节
/joyevents enable  <玩法>          # 启用（立即生效并写回配置文件）
/joyevents disable <玩法>          # 停用（同时回滚血量等副作用）
/joyevents trigger <玩法>          # 立刻触发一次，不用等周期
```

玩法 ID：`position_swap`、`shared_health`、`random_teleport`、`loot_gamble`

**配置文件**：玩法参数在 `config/joyevents-server.toml`，HUD 显示在 `config/joyevents-client.toml`改完保存即生效，不必重启游戏想让某个存档用不同规则，把前者复制到该存档的 `saves/<世界名>/serverconfig/` 覆盖即可

> **模组更新后不需要删除配置文件**：新增的选项会自动补上默认值、你改过的值会保留，被移除的旧选项与写错的条目会自动清理（日志里会有一行 `Configuration file ... is not correct. Correcting`）只有在你想恢复出厂设置时才需要删掉它

**规则由谁生效**：玩法规则是**服务端的规矩、全局生效**，登录时自动同步给每个客户端——别人装不装模组、本地文件写了什么都不影响；HUD 显示则是**各自本地生效**，各管各的远端服务器的服务端配置客户端无法修改（请用上面的命令或改服务端文件）；单人开局域网时本模组会改用自带配置入口，房主仍可修改

**HUD**：玩法运行时屏幕左上角显示倒计时（位置互换还显示目的地），可在 Client Config 里逐项开关；按 F1 或开启 F3 时自动避让

## 从源码构建

```bash
./gradlew build          # 产物在 build/libs/joyevents-<版本>.jar
./gradlew runClient      # 开发客户端
./gradlew runServer      # 开发服务端（首次需先同意 run/eula.txt）
```

需要 JDK 21

## 注意事项

- 旁观者永不参与任何玩法；创造模式玩家默认不参与共享生命（可配置）
- 物品赌博的 9 种触发方式**默认全部关闭**，开启玩法后要至少打开一种，否则永远不会触发
- 物品赌博默认 50%/50% 相当凶：挖一秒方块就可能丢掉一整格材料，且有 1/4 概率同时替换一格想长期玩建议调低（例如获得 40% / 丢失 10%）它只作用于背包 36 个主格，数量受物品自身堆叠上限限制（工具类最多 1 个）
- 共享生命 B 模式的共享条**不随人数变化**，人越多整体越脆；吸收之心（金苹果额外血量）在该模式下不生效，但"吃饱回血快"依然有效
- 共享生命 A 模式没有绝对伤害上限：100% 时一人挨 6 点、3 人合计掉 18 点，容易被打崩，建议调到 30%~50%
- 世界里没有任何玩家时，所有倒计时都会停住，不空转
